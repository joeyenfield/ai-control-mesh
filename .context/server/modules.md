# Server: module map

Part of [Server (`server/agent_server/`)](README.md). The core modules: storage, configuration, recording, routing, the fleet, security and distribution. Feature modules are in [features.md](features.md).

## Module map

| Area | Modules | Key symbols |
| --- | --- | --- |
| Database | `db/__init__.py`, `db/schema.py`, `db/migrate.py`, `db/kv.py`, `db/legacy.py` | `Database` (`write()`/`read()`, `size`, `close`, `hold_lock` (a process-long PostgreSQL advisory lock), `transaction_lock` (one until the write ends; the issuer's); SQLite WAL + BEGIN IMMEDIATE, PostgreSQL schema translation), `Writer` (`submit`, `flush`, `close`), `pack`/`unpack` (gzip), `sqlite_url`, `redacted`; `API_SCHEMA` `mesh`, `AUTH_SCHEMA` `mesh_auth`; `migrate` (`API_STEPS`, `AUTH_STEPS`, `schema_version`, advisory lock), `grant_issuer`, `ISSUER_READS`; `kv.upsert`/`get`/`put`/`get_meta`/`put_meta`/`secret`; `legacy.import_settings`/`import_sessions` |
| Config | `config.py`, `defaults.py`, `config_io.py`, `commands.py` | `Settings` (`load(database=True)`, `open_database`, `database_address`, `_configure` (stored settings, environment on top), `_store_config` (code-built Settings write theirs), `backend`, `backend_for`, `profile`, `update_network_config`, `update_models`, `set_retention`, `save_backend`, `remove_backend`, `upcoming_listen`), `seed`, `sync_builtin_agents`, `stored_config`, `validate_models`, `Backend` (`name`, `url`, `type`, `machine`, `container`, `options`), `serves()`, `BACKEND_TYPES`, `NATIVE_PROTOCOLS`, `MACHINE_TYPES`, `PROVIDER_NAMES`; `defaults.PROXY`/`INTERCEPT`/`BACKENDS`/`DEFAULT_BACKEND`/`MODELS_YAML`/`AGENTS_YAML`; `config_io.export`/`dump`/`parse`/`apply`, `put_agent`/`delete_agent`/`reset_agent`; `commands.main` (`agent-server config export|import`, `db info|migrate|import`) |
| Shared state | `runtime.py` | `Runtime` (`db`, `track` → `attach` → `stream_object`/`progress` → `complete`, `proxy_error`, `resolve_session`, `agents()`, `prune`/`prune_daily`), `upstream_client` |
| Recording | `sessions.py`, `telemetry.py`, `live.py`, `chat.py` | `SessionStore(db)` (memory authoritative for open sessions, written behind; `records`, `query_requests` (limit, before, model, kind), `traced`, `totals`, `recent`, `prune(before)`), `RequestTelemetry` (`kind`: api, intercept, upgrade, tunnel, mcp; `apply_ollama_stats` and `stream_deltas` read Ollama, OpenAI Chat and Responses, Anthropic and Gemini `generateContent` usage and text, the last bare or in the Code Assist API's `response` wrapper), `LiveHub` (memory only), `Chats` (the `chat_index` table), `read_traces` (batched) |
| Agents | `agents.py` | `AgentDefinition.render`, `load_agents(db)` (the `agents` table, re-read on every call), `parse_agents`, `stored_agents`, `_render` (a template with a missing placeholder is dropped) |
| Translation | `translate/` | `openai_to_ollama`/`OpenAIStreamTranslator`, `anthropic_to_ollama`/`AnthropicStreamTranslator`, `apply_profile` |
| Providers | `strata.py`, `model_runner.py` | `key_for`/`with_key` (container key, `STRATA_API_KEY`, or the machine's), `with_container_key` (a llama.cpp container's key; `managed_keys` holds every keyed container's), `upstream_path` |
| Fleet | `fleet.py`, `tunnels.py`, `containers.py`, `mcp.py` | `Fleet(db, sessions)` (`connect`, `message`, `ask`, `launch`, `shell`, `remove`/`restore`, `moved`, `machine_for`), `allowed`, `FEATURES`, `ADMIN_FEATURES`; `TunnelHub.base_url`; `ContainerManager`, `validate_spec`, `KEYED_ENGINES` (strata, llamacpp), `KeyStore(db)` (secrets `container-key:<name>`); `mcp.usable`/`choose` |
| Security | `auth.py`, `access.py`, `remote.py` | `AuthMiddleware`, `PROTECTED_PREFIXES`, `PUBLIC_PATHS`, `SITE_ADMIN_ONLY`, `ADMIN_ONLY`, `ROOT_TENANT`, `same_tenant`, `administers`, `Auth` (`identify` by introspection, `identity_for`, `account_version`, `check_password`), `AuthUnavailable`, `UserStore(db, readonly=False)` (`initialized`, `account_version`), `Identity`, `request_identity`; `can_view`/`can_control`/`is_owner`, `client_tags`, `sharing_tags`, `SERVER_TAGS`; `RemoteAccess.trusted`, `same_origin`, `write_secret`/`read_token` |
| Issuer (`agent-auth`) | `issuer.py`, `issuer_pages.py`, `relay.py` | `relay` (the browser's address the API names on its `/token` calls, with an HMAC proof under the introspection secret, so the issuer's per-address limit counts browsers, not the API); `issuer_pages` (the branded sign-in, device and problem pages, `STYLESHEET` for `/sign-in.css`); `create_auth_app`, `Issuer` (`client`, `provision`, `active`, `rate`, `csrf`, `page`, `finish`, `transaction_cookie`), `State(db, legacy_dir)` (`mesh_auth.records` with an `exp` column, the signing key in `mesh_auth.secrets`, the import of an older `issuer.sqlite3`), `state_database`, `accounts_database`, grants `CodeGrant`/`RefreshGrant`/`DeviceGrant`/`ServiceGrant`, `main` (`agent-auth`, `agent-auth client add|remove`) |
| I/O | `intercept.py`, `certs.py`, `websocket_tap.py`, `terminals.py` | `InterceptProxy.serve_tunnel`, `CertificateAuthority(db, directory)` (key in secret `intercept-ca`, public `ca.pem` and bundle written to `directory`), `WebSocketTap`, `TerminalHub` (output written as `terminal_chunks` every 64 KB or 1 s, `LOG_LIMIT` 64 MiB) |
| Distribution | `version.py`, `downloads.py`, `fetch_builds.py`, `installer.py`, `openapi.py`, `ui_build.py` | `PROTOCOL`, `MIN_PROTOCOL`, `VersionMiddleware`; `Downloads` (only `SHA256SUMS` files); `SAFE_URL`; `TAGS` |
| Routes | `routes/` | `compat` (agents), `management` (console), `machines` (fleet and provider relay), `terminals`, `mcp`, `proxy`, `containers`, `auth` (browser sign-in, organizations, users) |
| Tools | `benchmark.py` | `agent-benchmark`, runs `benchmarks/tests/<name>/` |
| Local instance | `local.py` | `agent-server local start\|stop\|status` (`main`, dispatched first in `app.main`): the API and agent-auth as two detached children (`python -c` with the `MARK` comment) on `127.0.0.1`, OIDC on `http://localhost:<port>` (19999/20000, kept in `local.json`). One folder (`instance_home`: `AI_PROXY_LOCAL_HOME`, else `%LOCALAPPDATA%\AI Control Mesh`, `~/Library/Application Support/AI Control Mesh`, XDG `ai-control-mesh`) holds `logs/` (SQLite), `oidc/`, `private/first-user-password` and `secrets.json` (0600: introspection secret, vault key; made once by `Instance.secrets`, given to the children only by environment). `Instance.environment` drops every inherited `AI_PROXY_*`. The API starts first (migrations, the first `admin`), then the issuer; ready means `/api/auth/status` names the expected issuer and audience and the issuer's discovery its own name. `stop` kills only processes whose id, start time and command-line mark match (`running`), their trees with them. `status --json` (`status_json`) is what agent-tray reads, with the server's `public_url` from `/api/auth/status` (public). `start(..., overrides=)` puts variables into the children's environment last: the all-in-one image's `AI_PROXY_HOST=0.0.0.0` and its `MESH_ADMIN_PASSWORD` as `AI_PROXY_USERNAME`/`PASSWORD`. Tests: `test_local.py` |
| Several processes | `cluster.py`, `roles.py`, `internal.py` | `Cluster` (`LocalCluster` in one process, `RedisCluster` with `AI_PROXY_REDIS_URL`; `fakeredis://<name>` in tests): sync keys and counters (`get`/`set`/`incr`/`hincrby`/`keys`), `publish`/`on` (messages to the other processes, never to the sender), `leader(name, ttl)` (leases), `pods()` (heartbeats every `HEARTBEAT`, gone after `POD_TIMEOUT`; `beacons` add fields), `call`/`stream` (an internal call to one process), `seal`/`unseal` (AES-GCM from `AI_PROXY_INTERNAL_TOKEN`); `roles.parse`/`check`/`role_of`/`filter_routes` (routes dropped by the module that registered them, `create_app`'s `registered`); `InternalEntry` (the internal listener: token check, then the same app, `scope["state"]["internal"]`), `InternalGate` (the public port never serves `/internal/*`), `TerminalForward` (a viewer of a terminal hosted elsewhere is proxied there whole), `register` (`/internal/fleet/{id}/ask\|launch\|shell\|tunnel`, `WS /internal/tunnels/{id}`, `/internal/live`), `metrics` |
| Blob storage | `blobs.py` | `from_environment` (`AI_PROXY_BLOB_URL`: None for the database, `FileBlobs`, `S3Blobs` with `sign` (SigV4) and `Credentials` (static or web identity)); `session_prefix` (`tenant/<org>/<yyyy>/<mm>/<session>`), `pack_trace`/`unpack_trace` (messages as `{"$block": sha256}`, once per session), `parallel` |
| Server stats | `stats.py` | `ServerStats.sample()` for `GET /api/server/stats` (site admins): psutil CPU, memory, swap, `network` (running totals over the interfaces that aren't loopback; the console works out rates), the process (with `open_files` and `connections`, null where the system refuses), each disk holding `log_dir`/`dist_dir`, the database (`database: {kind, bytes}`); folder sizes walked on a background thread at most every `FOLDER_TTL` (300 s), never on the request. `live(runtime)` (called by the route on the event loop, which owns what it counts) adds this process's own counts under `live`: requests in flight and the access log's totals and per-minute counts, open WebSockets by kind (`_socket_kind` on the access log's open entries), live streams, sessions, the fleet (machines, tunnels), shared terminals and viewers, intercept tunnels, links, the write queue and `cluster.pods()` as `nodes`. Nothing is saved, and with several processes each answers for itself. For Prometheus: `exposition(metrics, common)` writes `Metric` tuples as text (a None value is left out), `server_metrics(runtime)` adds the dashboard's numbers to `internal.metrics` (the internal port's `/metrics`, and `GET /api/server/metrics` for site admins on the public port), and `machine_metrics(sample)` is a machine's load sample as `agent_machine_*` for `GET /api/machines/{id}/metrics?format=prometheus` |
